## 正文

### 代码块（围栏）

```C++
#include <Windows.h>
#include <iostream>

int main() {
	// 获取当前系统时间
	SYSTEMTIME sysTime;
	GetLocalTime(&sysTime);

	// 用户输入新的系统时间信息
	std::cout << "请输入新的系统时间：" << std::endl;
	std::cout << "年份: ";
	std::cin >> sysTime.wYear;
	std::cout << "月份: ";
	std::cin >> sysTime.wMonth;
	std::cout << "日期: ";
	std::cin >> sysTime.wDay;
	std::cout << "小时: ";
	std::cin >> sysTime.wHour;
	std::cout << "分钟: ";
	std::cin >> sysTime.wMinute;
	std::cout << "秒数: ";
	std::cin >> sysTime.wSecond;
	std::cout << "毫秒: ";
	std::cin >> sysTime.wMilliseconds;

	// 调用SetSystemTime函数设置系统时间
	if (SetSystemTime(&sysTime)) {
		std::cout << "系统时间已成功设置！" << std::endl;
	} else {
		std::cout << "设置系统时间失败！错误码：" << GetLastError() << std::endl;
	}

	return 0;
}
```
围栏式代码块在默认时为半收缩状态，单击底部会将其展开，再次单击底部会将其恢复至半收缩状态；左上角按钮具有完全收缩功能，该按钮位于代码块标题头的最左处，单击进行切换；右上角按钮具有复制代码功能，该按钮位于代码块标题头的最右处，且由此处复制的代码不会附加版权信息。

## 评论系统

本站使用 Twikoo 作为评论系统

评论区通常位于页面底部栏上方位置，

评论区由两大板块组成（发送新评论与已有评论）组成。其中，发送新评论由 10个部分，分别是头像、昵称栏、邮件栏、网站栏、正文栏、插入表情按钮、插入图片按钮、文本样式按钮、浏览按钮、发送按钮所构成。已有评论由 4 个部分组成，分别是已有评论数（不包括回复评论）、刷新评论按钮、已有评论、展开/收起按钮所组成。
下文将详细讲述其作用

---

![PNG](https://unpkg.com/admincmd-blog-img-0@1.0.2/post/20241006130340_help_twikoo_1.png)
为更加具体的描述，请参照上图为依据，图中框内的代号为下文中所描述的位置依据（注：具有相同作用和功能的元素有相同的代号）

### 1
评论标题，标志着评论元素开始

### 2
头像，在输入 QQ 邮箱时会获取指定 QQ 账号的头像；在输入与 weavatar 绑定的邮箱时也会获取绑定头像。

### 3
昵称栏，用于输入昵称以及 F 元素的显示。
（必填）
格式：文本

### 4
邮箱栏，用于回复通知以及 2 元素的特殊用途。
（必填）
格式：文本

### 5
网站栏，用于 F 元素的点击（点击进入此处所填 URL）
（可选）
格式：文本

### 6
正文，用于 13 元素的显示文本，该元素支持上下拖动改变大小，最大字符串长度：114514.
（必填）
格式：文本

### 7
插入颜表情，单击内部表情元素即可在 6 元素中插入表情（或表情占位文本）

### 8
插入图片，单击后上传图片即可在 6 元素中插入图片占位文本。
{% note info modern %}
在成功向 6 元素插入图片占位文本时，届时您的图片上传完毕。
{% endnote %}

### 9
Markdown 语法链接（GitHub 文档）

### A
预览按钮，单击时在按钮下方显示一个预览元素，以显示您的评论的渲染结果。

### B
发送按钮，用于发送评论。

### C
已有评论数（不包括回复评论）。

### D
刷新评论信息。

### E
指定评论发送者的头像。

### F
指定评论发送者的昵称。

### 10
指定评论发送者的相对时间。

### 11
点赞指定评论
再次点击可取消。

### 12
回复指定评论，若有回复评论，则在图标右部显示评论数。

### 13
指定评论正文，使用 Markdown 进行渲染。

### 14
指定评论发送者的系统环境，使用的浏览器.

### 15
注标，用于标注特殊评论，有以下注标。
- 博主
    由管理账户发出的评论（已登录管理面板）
- 置顶
    由管理账户置顶评论，该评论将保持为第一位。
- 审核中
    不可见。


### 16
在回复指定评论时取消本次评论行为。

### 17
展开剩余评论。

### 18
关于评论系统，以及评论系统官方链接。
