## 教程

### 创建文件
首先，我们往一个文件夹丢几个文件
，这里以a.ini 、b.ini、c.ini替代

然后，新建一个文本文件，名叫 desktop.ini
### 修改文件
写入以下内容

```INI
[LocalizedFileNames]
a.ini=d
b.ini=d
c.ini=d 
```
语法
```INI
[LocalizedFileNames]
[原始文件名]=[显示文件名]
;
```

注：原始文件名需包括扩展名，显示文件名不需
且无法修改显示文件名扩展名

搞完后保存退出

重启下资源管理器，或者电脑重启下，或者注销都行

就可以看到效果了
