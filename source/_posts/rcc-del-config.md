## 开头

上初中了，微机室的电脑换了，换了个叫锐捷云的系统~~居然是虚拟机：½Ýüꁛ❿ꃩꋥ=Š®訲髾￠~~
为了完成在没有网禁 U 盘的微机室上玩上 MC，研究出的东西：
不过研究了一下，发现客户端上有 4 个U口，但是不认u盘，推测应该是管理系统整的，因为有个*您的 USB 已被禁用*的消息
于是就开始反查，原来极域把密码丢到注册表里，于是就在注册表里开始找 RCC 这个关键词，

然后查到了，配置文件夹的位置：
```
 C:\Windows\RCC-Guest-Tool\
```
这个文件夹里有相当一部分是INI配置文件
这个文件夹里确实有密码，但是已经是哈希值了，无法直接写进去关闭程序。如果想逆向算出来，拜托，我只是想解一个USB……
不过这些配置都没有保护，直接让系统已普通权限保存，没有保护，直接便是一个普普通通的小文件，
所以大胆一试，把配置目录扔到桌面上，之后发现不起作用，可能是被缓存了。
解决方案是让程序重新加载配置文件，但主程序为了防止某些有技术含量的学生终止进程，对这个操作拒绝访问
重启也不行，重启了文件就被重置了
不过，我们发现他的程序居然是在当前用户工作的，所以注销账户便可以结束进程从而达到重新加载配置文件的目的

2026.2.8 添加
现在已经初三，没有微机课，所以只在此提一下
据说该密码是以MD5进行处理，且并未添加加盐处理，所以随便弄符合MD5的值改写进去，应该可以改写密码。

~~把进程权限守得死死的，真不怕有人偷配置走了~~

除此以外，网上还说密码是锐捷的官网域名，测试了下，不行

网络上也有说配置文件位于`C:\Program Files\RCC-Guest-Tool\`的，可能因版本而异

这个方法可以解：
- USB禁用
- 老师远控

不过解不了：
- 上网问题


## 实际操作

1.首先打开`此电脑`，打到`C 盘`

2.双击打开`Windows`目录

3.找到`RCC-Guest-Tool`文件夹

{%note simple %}
貌似会有两个 RCC 开头的，建议全部按第 4 步处理
{% endnote %}

4.把文件夹删掉，要权限就继续

5.按`Ctrl` + `Alt` + `Del` 呼出安全选项，然后`注销`

6.登录账户

{% note info modern %}
微机室电脑只要配有重启自动恢复的（系统盘）磁盘环境，重启便可以恢复至之前的状态。
{% endnote %}
