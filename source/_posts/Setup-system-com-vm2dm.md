### 创建虚拟机
装 VMware
打开 VMware Workstation，选择新建虚拟机
上面这几步应该不用说吧？

1. 到`安装操作系统`这一步,请在`安装程序光盘映像文件`这一栏选择你选下载的系统镜像
2. 客户端系统自己选你的版本
3. 名称和位置随意
4. 固件类型,一定要注意,以你要安装的电脑相符
{% note warning simple %}
一定要注意,以你要安装的电脑相符,否则操作系统 99% 无法启动

一般来讲,uefi 的电脑,其安全启动默认开启,所以是 uefi 的电脑最好把安全启动也给勾上,免得出一些奇怪的问题
{% endnote %}
{% note simple %}
如果你的电脑比较老,比如是 11 年的,那基本确定是 BIOS ,如果电脑很新,比如是 21 年的,那基本确定是 UEFI 

不过如果你不知道,自己去问度娘,或者去bing找一下
{% endnote %}

### MBR、GPT 分区表转换
安装过程出现以下情况,请按照提示操作:

{% hideToggle 说什么 GPT 分区表，什么 mbr 分区表不适用什么 EFI 啥的 %}
以下操作位于虚拟机。
{% note warning modern %}
进行该操作之前,请先备份好数据,因为操作后无法恢复

若要将磁盘转换为 GPT/MBR 磁盘,请在转换磁盘前备份数据，因为会删除所有分区或卷。
{% endnote %}

1. 按下 `Shift + F10` 打开命令提示符
2. 输入`DISKPART`回车进入磁盘管理命令行
3. 输入`list disk`查看磁盘列表
4. 输入`select disk 0`选择第一个磁盘
5. 输入`clean`清除所有分区

{% note info modern %}
若要删除受保护的磁盘（如类型为“系统”与“保留”），则需要在 Delete Partition 命令后添加 Override 参数
如果需要一次性将磁盘上所有分区删除，请使用 Clean 命令

例如直接使用`Delete Partition`命令删除则会返回
    虚拟磁盘服务错误:
    如果不设置强制保护参数设置，则无法删除受保护的分区

而使用`Delete Partition Override`命令删除则会返回
    DISKPART 成功删除了所选分区

{% endnote %}

如果是 mbr 分区表,不适用 efi
请参考

6. 输入`convert gpt`转换为 gpt 分区表

如果是 GPT 分区表,说什么不适用 legacy,请参考

6. 输入`convert mbr`转换为 mbr 分区表

然后
7. 输入`exit`退出命令行

## 物理机调配

把跑虚拟机的电脑关机

将你插上去的那张盘拔下来，咋装的咋拔
然后将盘插回之前的那台电脑

开机
要检测你的电脑是否已进入系统，有一个很简单的方法

把网线插入到电脑，看看指示灯是否亮起
{% note warning modern %}
请确保网卡驱动已正确安装！网线已正确插入
虚拟机内好了不代表现在就好
{% endnote %}

### 如果没好……

把除系统盘以外的盘全部断开数据线连接

{% note warning modern %}
请确保网卡驱动已正确安装！网线已正确插入
